# 🧠 My Problem-Solving Approach

For every problem, I try to follow this workflow:

```text
           ┌──────────────────┐
           │   📖 Read Problem │
           └────────┬─────────┘
                    ↓
           ┌──────────────────┐
           │ 💭 Think & Analyze│
           └────────┬─────────┘
                    ↓
           ┌──────────────────┐
           │ 📝 Design Approach│
           └────────┬─────────┘
                    ↓
           ┌──────────────────┐
           │ 💻 Write Code     │
           └────────┬─────────┘
                    ↓
           ┌──────────────────┐
           │ 🧪 Test Solution  │
           └────────┬─────────┘
                    ↓
           ┌──────────────────┐
           │ ✅ Submit        │
           └────────┬─────────┘
                    ↓
           ┌──────────────────┐
           │ 🚀 Learn & Improve│
           └──────────────────┘
```

### 💡 Golden Rule

> **Don't rush to the solution.**

First try to solve the problem yourself.

If stuck:

1. 🔎 Identify what you don't understand.
2. 📚 Learn the required concept.
3. 💭 Try again.
4. 👀 Look at an editorial/solution only if necessary.
5. 💻 Implement it yourself.
6. 🧠 Understand *why* it works.

Most solutions are written in **C++**.

### Compile

```bash

```

### Run

```bash
./solution
```

On Windows:

